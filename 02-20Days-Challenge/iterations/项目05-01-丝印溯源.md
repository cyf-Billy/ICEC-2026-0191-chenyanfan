## 2. 尚不能确认的部分

### 2.1 为什么读不出

- 原始照片是**视频截帧**（16:9，最大 828×465），不是微距照
- 唯一的 2275×1279 大图是手写 BOM 纸，不是板子
- 丝印在这种分辨率下糊成像素块，读出来的任何字符都不可信

### 2.2 主控（SOP-16）候选清单

| 候选类别 | 典型型号（举例） | 为什么怀疑是它 | 置信度 |
| --- | --- | --- | --- |
| 8 位 OTP 单片机 | 应广 PFS154/PMS150、中微 CMS8S 系列、辉芒微 FT60F 系列、义隆 EM78 系列 | 百元内小风扇的典型方案：SOP-16、内置振荡器、直驱数码管笔段、单路 PWM 驱动电机；成本 0.3~1 元 | 高（类别），低（具体型号） |
| 带段码驱动的 MCU | 中微 CMS1621 / 类似"MCU+LED 驱动"二合一 | 板上若找不到独立的数码管驱动 IC，说明笔段驱动被集成进主控 | 中 |
| 通用 8 位 MCU | STC8G1K08（SOP-16）、CH32V003（SOP-16） | 这两种常用于教学改造，但**原厂不会用**（成本高于 OTP 方案） | 低（原板），但改造时可用 |

**关键判据**：如果板上**只有一颗 SOP-16 而没有任何其他驱动 IC**，那它几乎必然是"MCU + 段码驱动"二合一，因为 3 位共阴数码管需要 3+8=11 根 IO，正好吃满 SOP-16。

### 2.3 `2001.11.30` 是什么

三种可能，按可能性排序：

1. **厂内生产/批次日期码**（2020-11-30 或 2001-11-30），最常见
2. 板厂的工单号
3. 型号后缀的一部分（可能性最低，位置不像）

判定方法：看同款板子的另一张图是否出现不同日期——同一型号不同批次日期会变，型号不会变。

### 2.4 充电管理 / 电机驱动（SOT-23 封装的小芯片）

| 功能 | 候选 | 判据 |
| --- | --- | --- |
| 单节锂电线性充电 | TP4054 / TP4056（SOT-23-5 版）/ TP4057 / LTH7 丝印 | 单节 14500 + 5V 输入 + 外围只有 2~3 个阻容，是典型线性充电电路 |
| 电机驱动 | 单颗 NPN 三极管（SOT-23，丝印如 `J3Y`=S8050 / `1AM`=MMBT3904）或小 MOS（`A09T`=AO3400） | 3.7V 有刷电机电流 <500mA，一级低边开关足够；若板上同时有续流二极管，则更确定是低边驱动 |
| 稳压 | 3.3V LDO（SOT-23，丝印如 `662K`=XC6206）或直接电池供电 | 若 MCU 工作电压 3.3V 则需要 LDO；若 MCU 直接吃 3.7V 则无 |

**这三颗都属于"能读丝印就能定型号"的类型**——丝印通常就是 3~4 个字母的代码（如 `J3Y`、`662K`），查代码表即可 100% 确定，不需要查数据手册。

## 3. 补拍要求（这是当前唯一的关键缺口）

拍 3 张，每张要求一样：

| 序号 | 拍什么 | 位置 |
| --- | --- | --- |
| A | 主控 SOP-16 正面 | 板子中央偏上，16 脚那颗 |
| B | 两颗 SOT-23 小芯片（充电 + 驱动） | 板子一侧，3 脚/5 脚的小黑块 |
| C | 板号丝印 + 日期码 | 板子边缘白字 |

**拍摄参数**（手机即可）：

1. 距离 4~6 cm，用**主摄**（不要用超广角）
2. 打开**补光或台灯**，光从侧面 45° 打，**不要正打**——正打会反光吃掉丝印
3. 轻点屏幕对焦芯片，等出现"对焦锁定"再拍
4. 同一位置拍 3 张，其中 1 张略微倾斜，防止丝印被反光挡住一半
5. 拍完当场放大看：**能读出字符才算过**，读不出就重拍

## 4. 溯源方法论（以后拆任何板子都能用）

1. **先记板号，不先记芯片**：板号能反查整机型号和方案商，比单个芯片有用得多
2. **丝印分三段读**：`型号/代码 + 批次 + 日期码`。型号通常在最长那行，日期码常是 `YYMMDD` 或 `YYWW`
3. **代码丝印要查代码表**，不能按字母猜（`J3Y` 是 S8050，`1AM` 是 MMBT3904，这类对应关系必须查）
4. **交叉验证三条线**：丝印 + 封装 + 外围电路。三者对得上才敢下结论
5. **实测兜底**：万用表量 VCC/GND 定电源脚，示波器看有没有 PWM 输出，确认是不是 MCU
