## 2. 尚不能确认的部分

### 2.1 为什么读不出

- 原始照片是**视频截帧**（16:9，最大 828×465），不是微距照
- 唯一的 2275×1279 大图是手写 BOM 纸，不是板子
- 丝印在这种分辨率下糊成像素块，读出来的任何字符都不可信

### 2.2 主控（SOP-16）候选清单

| 候选类别 | 典型型号（举例） | 为什么怀疑是它 | 置信度 |
| --- | --- | --- | --- |
| 8 位 OTP 单片机 | 应广 PFS154/PMS150、中微 CMS8S 系列、辉芒微 FT60F 系列、义隆 EM78 系列 | 百元内小风扇的典型方案：SOP-16、内置振荡器、直驱数码管笔段、单路 PWM 驱动电机；成本 0.3~1 元 | 高（类别），低（具体型号） |
| 带段码驱动的 MCU | 中微 CMS1621 / 类似"MCU+LED 驱动"二合一 | 板上若找不到独立的数码管驱动 IC，说明笔段驱动被集成进主控 | 中 |
| 通用 8 位 MCU | STC8G1K08（SOP-16）、CH32V003（SOP-16） | 这两种常用于教学改造，但**原厂不会用**（成本高于 OTP 方案） | 低（原板），但改造时可用 |

**关键判据**：如果板上**只有一颗 SOP-16 而没有任何其他驱动 IC**，那它几乎必然是"MCU + 段码驱动"二合一，因为 3 位共阴数码管需要 3+8=11 根 IO，正好吃满 SOP-16。

### 2.4 电机驱动：已确认（`2302` N-MOS）

| 功能 | 结论 | 判据 |
| --- | --- | --- |
| 电机驱动 | ✅ **N 沟道 MOSFET，丝印 `2302`**，即 SI2302 / AO3400 一类（20V / 2~4A 级） | `photo-05-16` 中 `M+` 焊盘旁的 SOT-23 器件，表面印字 `2302` 清晰可读；且栅极走线来自主控、源极接地、漏极接 `M+` 侧，构成标准**低边开关** |
| 单节锂电线性充电 | ⚠️ 仍待确认（候选 TP4054 / TP4056 / TP4057 / LTH7 类） | 单节 14500 + 充电口 + 外围只有 2~3 个阻容，是典型线性充电拓扑；但这颗的丝印在照片里被反光挡住 |
| 稳压 | ⚠️ 待确认（可能是 3.3V LDO，也可能 MCU 直接吃 3.7V） | 板上未见明显 LDO 三脚器件，需实测 MCU 供电脚电压 |

**为什么"2302 + M+"能确认低边驱动**：`M+` 是电机正极直连电池正，电机负极回到 MOS 的漏极，MOS 源极接地。这样主控只需给栅极一个 PWM 就能调速，且驱动电压低、成本最低——这是百元内小风扇最常见的做法。若主控确实输出了 PWM，那"三档调速"就是靠这颗 MOS 实现的，而不是靠调压。

### 主控补拍的关键技巧（这次失败的原因就是反光）

`photo-05-16` 已经证明了微距可行，但**芯片表面被灯光反射糊成一片白**。下次只改一件事：

1. **把光源移到与镜头成 70°~80° 的侧后方**，让芯片表面只反射到暗处
2. 关掉房间顶灯，只留一盏侧光（台灯或手机手电）
3. 拍之前用**指甲轻刮芯片表面**——工业丝印是激光刻的，反光常盖住；刮一下把表面油污去掉，字会清楚很多
4. 若仍读不出，把手机贴到**放大镜/显微镜**上拍（10~20 倍即可，学校实验室或工坊有）

## 4. 溯源方法论（以后拆任何板子都能用）

1. **先记板号，不先记芯片**：板号能反查整机型号和方案商，比单个芯片有用得多
2. **丝印分三段读**：`型号/代码 + 批次 + 日期码`。型号通常在最长那行，日期码常是 `YYMMDD` 或 `YYWW`
3. **代码丝印要查代码表**，不能按字母猜（`J3Y` 是 S8050，`1AM` 是 MMBT3904，这类对应关系必须查）
4. **交叉验证三条线**：丝印 + 封装 + 外围电路。三者对得上才敢下结论
5. **实测兜底**：万用表量 VCC/GND 定电源脚，示波器看有没有 PWM 输出，确认是不是 MCU
