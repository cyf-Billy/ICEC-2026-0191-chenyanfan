# 项目五 旧电器拆解 · 迭代记录

## 0. 先复盘：项目一为什么放弃

- 选的题目：项目一 低功耗终端
- 验收口径要求：**24 小时以上**的电池电压 / 功耗时序
- 实际卡点：
  1. 需要稳压电源 + 长时间无人值守的记录设备，我只有万用表和手机
  2. 宿舍夜间熄灯断电，采集必然中断
  3. 试采得到的是断续数据，无法构成"24 小时连续时序"，交上去等于自己证明没做
- 结论与动作：**当天止损，转项目五**。判断依据是——项目五的验收口径是「拆解分步照片 + BOM + 改造接线验证」，全是离散、可当场完成的证据，不依赖连续多日数据。
- 这次踩坑得到的规律：**选题前先看验收口径能不能满足，而不是先看题目有不有趣**。

## 4. 改造方案（候选，拆完再定）

- 方案 A：外部 5V 模块替换原变压器供电，验证原电路在 5V 下能否正常工作
- 方案 B：在电源入口串一个自锁开关 + 限流电阻 + LED 指示灯，做成"可见上电状态"
- 判定标准：改造后能连续通电 10 分钟不发热异常、功能与改造前一致，即算通过

## 5. 风险与预案

| 风险 | 预案 |
| --- | --- |
| 拆解损坏卡扣 | 先拍照再动手，卡扣用撬棒从缝隙进 |
| 电容残留高压 | 拆前断电静置 10 分钟，用万用表确认无电压再碰 |
| 丝印磨掉读不出型号 | 记录封装 + 引脚定义，用万用表实测推断 |
| 改造后不工作 | 保留改造前接线照片，可回退 |
