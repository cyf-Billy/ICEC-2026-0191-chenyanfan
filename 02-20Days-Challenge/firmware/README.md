# firmware / 阶段二源码

本目录按考核规范「02-20Days-Challenge/：阶段二源码、process_logs/ 与 iterations/」设置。

## 为什么现在是空的

当前阶段二选题是**项目五 旧电器拆解**（见 `../iterations/项目05-00-拆解记录与BOM.md`）。该项目属于拆解与逆向类任务，交付物是分步照片、BOM 与供电/控制框图，**不产生固件代码**。

保留本目录是为了让 `02-20Days-Challenge/` 与规范要求的三个子项（源码、process_logs、iterations）结构对齐，避免后续追加开发时再改目录。

## 若追加开发，代码放这里

计划中的延展装置「校园声光提示」（MAX9814 麦克风 + ESP32-C3 + WS2812B 灯带）一旦进入实现阶段，源码按下列结构放在本目录：

```text
firmware/
└─ noise_light/
   ├─ noise_light.ino      # 主程序：采样 → 滤波 → 判档 → 灯效
   ├─ config.h             # 阈值、驻留时间、灯效参数
   └─ logic_check.py       # 判定逻辑离线验证（9 条用例）
```

判定逻辑与参数依据已完成设计文档，验证脚本 9 条用例全部通过；源码落地时直接按该文档实现，不重新设计规则。

## 约定

- 本目录只放**自己写的**代码，第三方库通过 `library.properties` 或 README 注明依赖与版本，不把库源码提交进来
- 每次提交对应一次可运行的改动，提交信息写清「改了什么、为什么」
